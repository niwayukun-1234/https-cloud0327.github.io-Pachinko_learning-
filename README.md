## なぜ作ったか

単語帳の暗記は、正しく答えても何も起きないので続きにくいものです。
一方でパチンコには「当たった!」という強い気持ちよさがあります。
その **ごほうびの感覚を英単語の正解に結びつければ、つい続けたくなる学習になるのでは** と考えて作りました。
画面の演出・音・玉の増減で、1問ごとに手応えが返ってくることを大事にしています。

## できること

- **しっかり勉強(学習モード)** … 1回10問の4択クイズ。1問6秒の制限時間があり、英単語の発音も聞けます
- **正解すると大当たり演出** … 全画面に玉が降る演出と効果音。連続正解(コンボ)ほど獲得玉が増え、3連続正解では特別な演出とボーナス玉
- **確変(ラッシュ)** … 連続正解を続けると「確変」に突入し、専用BGM・豪華演出・ボーナス玉。設定でオフにもできます
- **間違えると失敗演出** … 不正解や時間切れでは玉が減ります(連続で間違えるほど大きく減る)
- **サクッと勉強(パチンコモード)** … パチンコ台の画面で「PUSH 発射」を押すと、1回転ごとに英単語クイズ(TOEIC 500〜600点レベル・100問)を1問出題。オート回転、打ち出し速度の調整、プレイ中の途中結果の確認ができます
- **リザルト画面** … 正解率・スコア・評価ランク・獲得玉・学習時間を表示し、間違えた単語だけをもう一度解けます
- **単語図鑑** … 学習した単語を検索・絞り込みで一覧し、例文や学習履歴を確認。「要復習」の単語から復習を始められます
- **BGMは画面を見ているときだけ** … 別のタブやアプリに切り替えると音楽が止まり、戻ると続きから流れます
- **設定** … 音のオン/オフ、画面の明るさ、確変のオン/オフ

## 遊び方

1. 上のリンクをスマホで開き、「はじめる」を押す
2. 「パチたん(続きから)」か「ゲスト」を選んでホームへ
3. **しっかり勉強** で10問の英単語クイズに挑戦。正解で玉が増え、間違えると減ります
4. 貯まった玉で **サクッと勉強**(パチンコモード)へ。PUSHを押すたびにクイズが1問出ます
5. 終わったらリザルト画面や単語図鑑で、間違えた単語を復習

> 音が出ます。最初の1タップでBGMが流れ始めます(ブラウザの自動再生制限のため)。

## 技術的な詳細

### 技術スタック

| 分類 | 使用技術 |
| --- | --- |
| フロントエンド | React 19 + TypeScript |
| ビルド | Vite |
| ルーティング | React Router(`HashRouter`。GitHub Pages でもリロードで404にならない) |
| 状態管理 | React Context + `useReducer`(`src/store/AppContext.tsx`) |
| データ保存 | ブラウザの `localStorage`(所持玉・学習実績・設定)と `sessionStorage`(進行中の10問セッション・結果) |
| 演出 | CSS アニメーション、SVG、Canvas(パチンコ盤面の玉) |
| サウンド | `HTMLAudioElement`(BGM・効果音)、Web Audio API(合成音)、Web Speech API(英単語の読み上げ) |
| テスト / Lint | Vitest + Testing Library、oxlint |
| 公開 | GitHub Pages(`gh-pages` ブランチ) |

サーバーやデータベースはありません。すべてブラウザ内で動き、データは端末に保存されます。

### ゲームルール(コード上の値)

- 学習モード: 1セッション10問、1問6秒(`src/data/learn.ts`, `src/pages/Learn/Learn.tsx`)
- 正解の獲得玉: 10玉 × 連続正解数。確変ボーナスは +100玉
- 3連続正解時と確変1回目は長い演出になり、途中で追加ボーナス(50 / 100 / 150玉、まれに 500 / 1,000玉)が出る(`src/lib/bonus.ts`)
- 不正解・時間切れ: 10玉 × 連続不正解数(最大50玉)を減算
- 確変: 4〜7連続正解のどこかでランダムに突入し、2〜3問続く。確変中は難しい単語が優先して出題される
- パチンコモード: 1回転10玉。抽選は通常1/5で1,000玉、当選後5回転のRUSH中は1/2で1,500玉(`src/pages/PachinkoMode/hanamai/lottery.ts`)。抽選はクイズの正誤とは独立で、回答結果は学習記録に反映される

### 単語データ

- 学習モード・単語図鑑: `src/data/words.ts`(発音記号・品詞・例文・よく使う表現つきの英単語 17語)
- パチンコモード: `src/data/toeicQuiz.json`(TOEIC 500〜600点レベルの4択クイズ 100問。1周するまで同じ問題は出ない)

ホーム画面のレベルや「覚えた単語」数、図鑑の全単語数などの一部は、初回表示用の初期値として `AppContext.tsx` に入っています。ホームの難易度(TOEICスコア別)の選択は、現在は表示上のもので、出題内容は変わりません。

```
.
├── README.md            … このファイル
├── docs/screenshots/    … README用のスクリーンショット
├── tanpachi-app/        … パチ単語アプリ本体(Vite + React + TypeScript)
│   ├── src/
│   │   ├── pages/       … 画面ごとのフォルダ(Welcome, Home, Learn, Correct, Fail, Result, PachinkoMode, Words など)
│   │   ├── components/  … 複数画面で使う部品(ヘッダー、玉カウンター、クイズモーダル、設定メニューなど)

│   │   ├── lib/         … 効果音/BGM、設定、ボーナス抽選などの小さな処理
│   │   ├── hooks/       … クイズ出題やカウントアップなどのフック
│   │   └── assets/      … BGM・効果音・画像

│   └── README.md        … 開発者向けの詳しいメモ(画面ごとの仕様・データの出どころ)

```

公開中のアプリは `tanpachi-app/` をビルドしたものです。`react-sample-app/` はアプリでは使われていません。

### ローカルで動かす

Node.js(npm)が必要です。

```bash
cd tanpachi-app
npm install
npm run dev        # 開発サーバー(表示されたURLをブラウザで開く)
```

その他のコマンド:

```bash
npm run build      # 型チェック + 本番ビルド(dist/ に出力)
npm run preview    # ビルド結果をローカルで確認
npm test           # テスト
npm run lint       # Lint
```

### デプロイ(GitHub Pages)

公開は `gh-pages` ブランチの中身がそのまま配信される仕組みです(自動デプロイは設定していません)。

1. `tanpachi-app` で `npm run build` を実行する
2. `gh-pages` ブランチの中身を `tanpachi-app/dist/` の中身で置き換え、空の `.nojekyll` ファイルを置く
3. `gh-pages` ブランチをコミットして push する

`vite.config.ts` で `base: './'`(相対パス)にしているので、リポジトリ名のサブパスで公開してもそのまま動きます。
