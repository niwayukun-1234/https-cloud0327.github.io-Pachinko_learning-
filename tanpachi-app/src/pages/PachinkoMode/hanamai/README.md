# 花舞の移植

移植元: `cloud0327/hanamai` / `37072d1329deb064ef6b400968bf6c7c3be69b1f`。
筐体・画像・図柄・3段カットイン・音声を移植し、独立抽選とRUSHを追加。

## ゲームと学習の接続

- 1回転10玉、通常1/5で1,000玉。当選で5回転のRUSH。
- RUSHは1/2で1,500玉。最終回の当選も1,500玉で、再当選時は残り5回転。
- `lottery.ts` はクイズ正誤を受け取らない。ランダム抽選と学習成績は独立。
- 1回転につき既存の英単語クイズを1問出題し、回答時に`spinQuiz`を1回だけ呼ぶ。
- AppContextの所持玉・回転数・大当たり・正答率・連続正解・履歴・学習実績を同時更新する。
- クイズ表示中は正解を777や玉報酬と表示せず、「学習記録に反映」と表示する。
- 回答前に離脱すると回転は未確定。回答後は演出を中断しても確定済みの記録が残る。
- RUSHと途中結果はページ内セッション。画面遷移・リロードで終了する。共通所持玉は既存の `tanpachi:v1` に保存される。
- デモはクイズ・所持玉・RUSH・記録を変更しない。
- オートは次の回転のみ開始し、クイズ回答はプレイヤーが行う。メニュー・途中結果を開いている間は開始しない。

## 互換性

CSSとアニメーション名を花舞のスコープへ限定し、既存のDevice/ホーム/クイズ/途中結果のスタイルを変更しない。
PNGは原本のまま`assets/`へ移植し、ViteのURL importで相対パスの配信にも対応。
Web Audioは音声ONの操作から開始し、出題時には日本語の掛け声を止めて英単語発音を優先。画面を離れると停止・破棄する。
従来の`usePachinkoSpin`は他の利用箇所と型互換性のため保持。元の正解報酬モードも引き続き動作する。
